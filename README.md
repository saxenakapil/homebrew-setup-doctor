# Saxenakapil Setup-doctor

## How do I install these formulae?

`brew install saxenakapil/setup-doctor/<formula>`

Or `brew tap saxenakapil/setup-doctor` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "saxenakapil/setup-doctor"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
